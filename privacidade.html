Política de privacidade

O que o site citavel.ai coleta, por quê, onde guarda e como você pede acesso ou exclusão.

Quem é o controlador

O controlador dos dados é a CITÁVEL, operação de reputação em inteligência artificial da Desigual IA Labs, em Birigui, São Paulo. Endereço: Av. Youssef Ismail Mansour, 265, Sala C, Birigui, SP, 16202-484. Pedidos relativos a dados pessoais vão para endrigo@citavel.ai.

Que dados são coletados

Ler este site não exige cadastro e não cria conta. Dados pessoais só chegam quando você mesmo os envia:

  • Formulário de diagnóstico e contato: nome, e-mail, telefone ou WhatsApp, nome da empresa, setor, cidade e o que você escrever no campo aberto.
  • Registros técnicos de servidor: gerados automaticamente pela hospedagem a cada visita, como endereço IP, data, hora e página acessada.

Para que os dados são usados

Exclusivamente para responder ao seu contato, executar o diagnóstico solicitado, elaborar proposta e conduzir a relação comercial. Nada é usado para publicidade comportamental, e nenhum dado pessoal é vendido, alugado ou cedido a terceiros com finalidade comercial.

Onde os dados ficam e com quem são compartilhados

O site é publicado como arquivos estáticos no GitHub Pages, responsável pela entrega das páginas e pelos registros técnicos de acesso. O formulário é processado por uma função hospedada na Vercel e a notificação é enviada pelo serviço de e-mail Resend. Esses fornecedores atuam como operadores e podem processar dados fora do Brasil.

Um ponto específico do nosso trabalho

O diagnóstico e a Radiografia PULSO medem o que as inteligências artificiais respondem sobre marcas, a partir de perguntas públicas sobre produtos, serviços e mercados. Não envolvem dado pessoal de clientes finais da marca analisada, e nada do que você nos envia é usado como entrada de treinamento de modelo de inteligência artificial.

Cookies e medição

Este site não usa cookie de publicidade nem pixel de rede social para rastrear visitantes entre sites.

Por quanto tempo os dados ficam guardados

Contatos comerciais são mantidos enquanto durar a conversa e pelo período necessário para cumprir obrigações legais e contratuais decorrentes dela. Encerrada a relação e vencidos esses prazos, os dados são eliminados ou anonimizados.

Seus direitos

A Lei Geral de Proteção de Dados (Lei 13.709/2018) garante a você confirmar a existência de tratamento, acessar seus dados, corrigir dado incompleto ou desatualizado, pedir anonimização ou eliminação, solicitar portabilidade, saber com quem os dados foram compartilhados e revogar o consentimento a qualquer momento. Escreva para endrigo@citavel.ai. Pedidos são respondidos em até quinze dias.

Mudanças nesta política

Se a forma de tratar dados mudar, esta página muda junto e a data de atualização no rodapé é alterada. Vale sempre a versão publicada aqui.
